## Sobre o projeto

Análise estatística da base **Customer-Churn-Records**, de uma instituição bancária, para identificar quais atributos de clientes mais se associam ao cancelamento (`Exited`). O trabalho foi conduzido em planilha (Excel/WPS), com engenharia de atributos por faixas (idade, score de crédito, tenure, saldo, salário e pontos), segmentação de coortes (clientes ativos vs. cancelados), tratamento de outliers via IQR nas variáveis contínuas `Idade` e `Balance`, e cálculo de Information Value (IV) para medir o poder discriminante de cada variável. O resultado é uma triagem objetiva de atributos: `Complain` foi identificado como *data leakage* (IV = 1,99), enquanto `NumOfProducts` (IV = 0,72) e a faixa etária (IV = 0,65) despontam como os indicadores mais relevantes para retenção.

## Metodologia

- **Engenharia de atributos:** criação de faixas operacionais (`FaixaIdade`, `FaixaScore`, `FaixaTenure`, `FaixaSaldo`, `FaixaSalarial`, `FaixaPontos`) a partir das variáveis contínuas originais.
- **Segmentação de coortes:** separação da base entre clientes ativos e cancelados para comparação de perfil e comportamento.
- **Tratamento de outliers (IQR):** cálculo de quartis (Q1, Q2, Q3), limites inferior/superior e boxplots para `Idade` e `Balance`, gerando uma base secundária sem outliers.
- **Matriz de correlação:** checagem de colinearidade entre variáveis contínuas antes da etapa de seleção.
- **Cálculo de Information Value (IV):** mensuração do poder preditivo de cada variável (categórica e em faixas) em relação ao churn, seguindo a régua padrão (< 0,02 inútil · 0,02–0,10 fraco · 0,10–0,30 médio · 0,30–0,50 forte · > 0,50 muito alto/possível vazamento).
- **Triagem de atributos:** classificação final das variáveis com decisão explícita de inclusão/exclusão com base no IV (ex.: exclusão de `Complain` por vazamento de dados).
